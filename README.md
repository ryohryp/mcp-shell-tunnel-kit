# MCP Shell Tunnel Kit

Configuration and operational examples for [sonirico/mcp-shell v1.0.0](https://github.com/sonirico/mcp-shell/tree/v1.0.0) deployed over [OpenAI tunnel-client v0.0.14](https://github.com/openai/tunnel-client/tree/v0.0.14).

This repository is a deployment kit, **not** a fork or replacement for either upstream project. It shows an opt-in `run_script` configuration using fixed diagnostic commands, with file and Git writes disabled. See the `examples/` and `docs/` directories as they are added.

Never commit credentials, real Tunnel profiles, secrets, private logs or host-specific configuration. The sample files are examples, not a security guarantee.
